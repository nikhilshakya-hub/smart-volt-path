# EV Smart Dashboard

... Build a Complete Professional Frontend for EV Smart

Create a modern, fully responsive, professional frontend web application for my B.Tech final-year project:

Project Title

EV Smart: AI-Based Intelligent Electric Vehicle Charging Scheduler

Project Purpose

EV Smart is an intelligent electric vehicle charging management platform. The system helps EV users monitor battery status, view charging information, find charging stations, analyze electricity prices, and receive AI-based recommendations for the best charging time.

For now, build ONLY THE FRONTEND. Do not create a backend, authentication server, database, or real API integration yet.

Use realistic dummy/mock data throughout the application so the frontend looks fully functional. The frontend should be designed so that backend APIs can easily be connected later.
